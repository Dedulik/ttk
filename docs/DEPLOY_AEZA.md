# Запуск на VPS (Aeza) через Docker

Сервер: Ubuntu 22.04/24.04, от 1 ГБ памяти. Все команды выполняются на сервере по SSH.

## 1. Docker (один раз)

```bash
curl -fsSL https://get.docker.com | sh
```

## 2. Первый запуск

```bash
git clone https://github.com/Dedulik/ttk.git
cd ttk
docker compose up -d --build
```

Сайт откроется по адресу `http://IP-сервера:8000`, админ-панель — `http://IP-сервера:8000/admin`.

**Пароль администратора** сервер придумывает сам при первом запуске:

```bash
docker compose exec app cat /data/admin-password.txt
```

Почта — `admin@arena.local`. Учебного пароля `admin12345` на сервере нет: его знает любой, кто читал README.

## 3. Обновление до новой версии с GitHub

```bash
cd ttk
git pull
docker compose up -d --build
```

Ключ `--build` обязателен. Без него Docker запускает старый образ, и на сайте остаётся старая версия.

После обновления в браузере нажмите Ctrl+F5 (на телефоне закройте вкладку и откройте заново).

Карта манежа обновляется сама, если её не правили в конструкторе. Если правили — сервер её не трогает, чтобы не стереть вашу работу.

## 4. Забыли пароль или он «не подходит»

```bash
docker compose exec app python reset_password.py
```

Команда покажет новый пароль, снимет блокировку после неверных попыток и завершит старые сеансы.

Можно и через настройки: в файле `.env` рядом с `docker-compose.yml` укажите

```
ADMIN_PASSWORD=СвойПароль123
ADMIN_PASSWORD_RESET=1
```

Выполните `docker compose up -d`, войдите и **уберите строку `ADMIN_PASSWORD_RESET=1`** — иначе пароль будет сбрасываться при каждом перезапуске.

## 5. Домен и HTTPS

HTTPS нужен для съёмки панорам камерой телефона и для установки сайта как приложения.

1. Направьте домен на IP сервера (запись A). Своего домена нет — возьмите бесплатный по IP: `193-233-246-152.sslip.io` (точки в IP заменены дефисами), настраивать ничего не нужно.
2. В `.env`:
   ```
   DOMAIN=map.example.ru
   PUBLIC_URL=https://map.example.ru
   TRUST_PROXY=1
   APP_BIND=127.0.0.1:8001
   ```
3. Откройте порты и запустите с прокси:
   ```bash
   ufw allow 80/tcp && ufw allow 443/tcp
   docker compose --profile https up -d --build
   ```

Сертификат Let's Encrypt Caddy получит и продлит сам. Сайт будет по адресу `https://map.example.ru`. Сервер приложения теперь слушает только внутри машины, а старые ссылки `http://IP:8000` Caddy переадресует на https.

## Данные и резервные копии

База, пароль, ключ подписи и загруженные фото лежат в томе Docker `arena-data` (папка `/data` в контейнере) и переживают обновления. При каждом запуске сервер сохраняет копию базы в `/data/backups`.

Скачать копию на свой компьютер: админ-панель → «Безопасность» → «Скачать резервную копию».

`docker compose down -v` **удаляет том со всеми данными** (картами, пользователями, фото). Используйте эту команду, только если действительно нужно начать с нуля.

## Если что-то не работает

```bash
docker compose ps                 # контейнер должен быть в состоянии running (healthy)
docker compose logs --tail 100 app
```
